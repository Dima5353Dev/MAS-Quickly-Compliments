# MAS - Quickly Compliments

A Monika After Story submod that adds a **"Praise"** button for quicker access to Monika's compliment menu.

## Features

- Adds a **Praise** button to the MAS quick-access area.
- Opens Monika's compliment menu directly.
- Supports four languages:
  - English
  - Русский
  - Español
  - Português (Brasil)
- Four customizable button positions, making it easy to place the Praise button alongside other submods that add buttons to the MAS quick-access area.
- Option to hide the Praise button.
- Dedicated **Submod settings** menu.
- Settings are saved automatically.

## Requirements

- [Monika After Story](https://github.com/Monika-After-Story/MonikaModDev)

### Tested Versions
- **MAS 0.12.18**
- **MAS 0.12.15**

This submod was developed and tested with MAS 0.12.18 and 0.12.15.

## Installation

1. Download the latest release from the **Releases** section.
2. Extract the downloaded archive.
3. Copy the `Quickly Compliments` folder into your MAS `game/Submods` directory.
4. Start Monika After Story.

The resulting structure should look like this:

```text
Monika After Story/
  game/
    Submods/
      Quickly Compliments/
        header.rpy
        quickly_compliments.rpy
        Aller_Rg.ttf
```
## Settings

Quickly Compliments includes a dedicated Submod Settings menu.

## Language

You can choose between:

- English
- Русский
- Español
- Português (Brasil)

English is enabled by default.

## Button Position

You can choose between four available positions for the Praise button.

The available positions allow you to adjust the button around other submods that add buttons to the MAS quick-access area.

## Hide Button

The Praise button can be hidden at any time through the submod settings.

You can restore it later by selecting one of the button positions.

## Uninstallation

1. Close Monika After Story.
2. Open your MAS game/Submods directory.
3. Remove the Quickly Compliments folder.
4. Start MAS again.
